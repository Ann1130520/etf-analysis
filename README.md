# 📊 台股 ETF 四強情報戰情室 (0050 / 0056 / 00981A / 00940)

比照「貨櫃三雄情報戰情室」架構打造，專為台灣四檔代表性 ETF（**元大台灣50 0050**、**元大高股息 0056**、**主動統一台股增長 00981A**、**元大臺灣價值高息 00940**）設計的互動式投資分析戰情網頁。

---

## 🌟 核心模組一覽 (12 大功能分頁)

### 第一排：看盤與實戰買賣決策流
1. **戰情總覽 (`overview`)**：四強即時報價卡片（20MA/RSI、近一年配息、殖利率、三大法人買賣超）＋ 多市場互動走勢對照圖（累積報酬率 % / 價格點位切換，含台積電、加權、S&P500、費半、日經）。
2. **四強對決 (`comparison`)**：定量指標對比表（規模、經理+保管費、配息頻率、平準金、前三大持股）、六大維度戰力雷達圖、產業曝險佔比圖、證交所 T86 三大法人籌碼表、2026 配息實績摘要。
3. **技術與籌碼面 (`technicals`)**：5MA / 20MA / 60MA / 240MA 均線乖離率、RSI(14) 強弱與三大法人買賣超圖表。
4. **買賣建議專區 (`signals`)**：依即時市價與均線位置自動判定【強力加碼區】、【定期定額區】與【過熱再平衡區】，並整理三大退場/再平衡警訊。
5. **進場檢核與筆記 (`checklist`)**：8 大進場紀律檢核清單（動態計分）＋ 本機 `localStorage` 自動存檔存股筆記本。
6. **報酬情境試算 (`calculator`)**：定期定額複利動態模擬器（調整大盤年化報酬、主動選股 Alpha、每月金額與投資年數）＋ 個人 ETF 持股損益追蹤器。

### 第二排：成分股、總經資金、領息節稅與研究
7. **選股與成分股 (`industry`)**：拆解四大 ETF 選股邏輯、前十大成分股權重互動切換表、含積量集中度與殖利率/費用率比較圖。
8. **全球資金風向 (`geopolitics`)**：總經壓力測試情境切換 ＋ 六大資金傳導節點互動地圖（費半/AI、美10年債、台積電、換股潮、匯率外資、主動 Alpha）。
9. **費用與主被動對比 (`macro`)**：內扣費用率 (TER) 複利侵蝕模擬器（計算 00981A 追平 0050 所需的 Alpha 門檻）與四大流派百科表。
10. **除息節稅與現金流 (`dividend`)**：精算單次除息是否超過 NT$20,000 觸發 2.11% 二代健保補充保費（含平準金應稅比例調整）及 8.5% 股利可抵減稅額。
11. **ETF 新聞情報 (`news`)**：整合 Google News 即時新聞 RSS 與深度解讀，支援分類篩選與關鍵字搜尋。
12. **權威文獻回顧 (`literature`)**：彙整 Sharpe/Bogle 指數理論、Fama-French 多因子、Grinold & Kahn 主動管理定律與台灣 ETF 實證研究，支援一鍵複製 APA 引文。

## 🚀 如何啟動與更新即時數據

### 1. 更新最新台股報價、技術指標、法人籌碼與新聞
```bash
python update_data.py
```

### 2. 啟動本地戰情室伺服器（推薦）
```bash
python server.py
```
瀏覽器將自動開啟 `http://localhost:8089/index.html`（或直接雙擊 `啟動戰情室.bat`）。
